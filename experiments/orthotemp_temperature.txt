# Temperature conditioning (Harsh) on the temperature subset: 36 Orthoptera species,
# 855 temperature-labelled recordings (data/meta/orthotemp_manifest.csv).
# Same files in every condition:
#   none     - the plain model, no temperature input
#   real     - FiLM conditioning on (standardised temperature, missing flag)
#   shuffled - same FiLM model, temperatures permuted across training recordings
#              (architecture-matched control: any gain over it must come from the
#              temperature values themselves, not from the extra parameters)
# Mixup is off everywhere because it would mix two recordings but keep one temperature.

# MLP on handcrafted features (CPU, ~1 min per run)
--model mlp --data orthotemp --epochs 150 --batch 64 --wd 1e-4 --seed 42 --tag _none_s42
--model mlp --data orthotemp --epochs 150 --batch 64 --wd 1e-4 --temperature real --seed 42 --tag _real_s42
--model mlp --data orthotemp --epochs 150 --batch 64 --wd 1e-4 --temperature shuffled --seed 42 --tag _shuffled_s42
